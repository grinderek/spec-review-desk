# Описать существующий процесс

Владелец выбирает продукт, процесс и репозиторий для правил. Desk сохраняет этот
контекст в инициативе. ИИ исследует снимок исходников выбранного продукта и
предлагает небольшие этапы описания. После согласования границ этапа ИИ готовит
читаемые исполняемые правила с проверяемыми ссылками на реализацию.

Обнаруженное поведение остается предложением до согласования владельцем через
обычные карточки Desk. Исследование и подготовка правил не изменяют код приложений,
не запускают production и не создают согласования от имени владельца.

Проверено: 118 продуктовых проверок, включая четыре правила этого процесса;
`npm run typecheck`; пять существующих браузерных проверок создания инициативы
и карточек DSL. В отдельном временном продукте вручную пройден весь интерфейс:
создание, исследование, согласование границ, подготовка и одобрение карточки,
переход к строке сохраненного исходника. Для проверки потока использован
управляемый ответ агента; качество исследования настоящим ИИ еще не проверено.
Снимок шести репозиториев Monitoring собирается без изменения приложений
и занимает около 4,9 МБ. Отдельные технические тесты не добавлены.
