# Owner Git effects

Existing-initiative brief, input, research acceptance, domain and plan approval commands prepare
an explicit business decision and exact Git outputs under the worktree admission lease and
initiative scope lock. InitiativeOwnerGitRequested and the business facts are one atomic journal
batch. Derived files materialize only after this batch. Git completion is a separate confirmed
receipt; a failed or uncertain commit remains visibly pending and blocks execution admission.

A repeated interrupted command reuses its intent and public result. Upload retry therefore keeps
the original filename and input entry. The owner may also retry the recorded effect directly.
Restart reconciliation only recognizes an already completed commit or records a pending outcome;
it does not create a commit. The initiative screen exposes the pending operation and Retry commit.

Immutable states/<hash>.json binds the exact desired business metadata in each commit. The
journal and mutable YAML are explicit extra files because an intent cannot hash its own journal.
Brief and input outputs refer to immutable blobs by path and SHA-256. Large input bodies are not
embedded in journal JSON. Each intent includes only its required blob/view outputs, while the
source-backed Git protocol verifies size, bytes, mode and the committed Git blob.

Creation uses a separate repository-anchored worktree command journal, implemented by the
creation coordinator. Its stable creation, stream and command IDs produce deterministic initial
initiative journal bytes. Branch/worktree provisioning and initial Git commit are observable,
reconcilable effects; neither Git nor separate journals are claimed to be one atomic transaction.

Safe run artifacts reject invalid UTF-8, changing files and oversized encoded JSON with a typed
failed receipt. Retained Docker attempts remove auxiliary browsers, proxies and networks while
keeping terminal agent identity until receipt acceptance. Any live or unknown associated
container prevents finalization and replacement.
