# Устойчивое выполнение проверок

Сейчас результат проверки должен принадлежать одному запуску и версии исходников. Общий перезаписываемый файл не позволяет отличить завершенный прогон от оборванного и может показывать старый успех после изменения кода.

Desk записывает намерение и версию входа до запуска команды, сохраняет отдельный неизменяемый receipt и принимает только полный отчет этой попытки. При перезапуске Desk наблюдает уже запущенную работу и принимает готовый результат. Неизвестный исход требует явного нового запуска владельцем после проверки отсутствия живых процессов предыдущей попытки.

Контракты покрывают успешный и неуспешный отчет, неполный/чужой/дублированный отчет, восстановление receipt, пересборку view и устаревание результата после изменения исходников. Изменение является частью S4. Native package cutover и переход идентификаторов с названий на stable IDs остаются отдельным этапом.
