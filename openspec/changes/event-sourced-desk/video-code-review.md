## Fundamentals

[Видео в главе](https://code.abdullin.com/modules/event_sourcing/unit/02_event_sourcing_fundamentals),
длительность 16:33.9. Разобрана полная локальная автоматическая расшифровка звука, проверены
кадры с шагом 30 секунд на всем протяжении. Имена и термины сверены с главой; автоматическая
расшифровка не считается дословной авторской стенограммой.

| Интервал | Содержание |
| --- | --- |
| 00:00-02:06 | Состояние на выбранный момент выводится из предшествующих событий. |
| 02:06-07:36 | Транспортный пример показывает, какие сведения теряются при перезаписи таблиц. |
| 07:36-12:51 | События погрузки и выгрузки восстанавливают представления, включая промежуточное нахождение груза в порту. |
| 12:51-16:33 | Из той же истории строится новое представление маршрута груза. |

Видео соответствует содержанию главы. Для Desk существенно сохранять значимые промежуточные
переходы: запрос работы, ожидание владельца и подтвержденное завершение. Возможности новых
views ограничены фактически записанными данными.

## Event Storming

[Видео в главе](https://code.abdullin.com/modules/event_sourcing/unit/08_event_storming),
длительность 12:21.6. Полная автоматическая расшифровка разобрана, кадры проверены с тем же
шагом 30 секунд. Формат обзора через звук и последовательность кадров одинаков для обоих видео.

| Интервал | Содержание |
| --- | --- |
| 00:00-02:30 | Подготовка пространства, материалов и легенды. |
| 02:30-07:41 | Прошлые бизнес-события, временная линия, hotspots, идеи и возникающие группы. |
| 07:41-10:46 | Участники, общая картина и переход к отдельному процессу. |
| 10:46-12:21 | Уточнение actors, commands, views; прототип и обратная связь. |

Видео подтверждает итеративность моделирования. Для Desk предварительные review/initiative
scope остаются гипотезой до разбора конкретного процесса с владельцем. Рисование карты не
подменяет проверку рабочего среза и не создает требования встроить доску в продукт.

SHA-256 оригинальных видео:

- Fundamentals: `053d3193d12c2e705b1a50e74253bc341415d143d8eaf6267b4529c91514753f`.
- Event Storming: `48ad64a6700e5f667fd6832444f674f625518d997d4a6c1740fe7f02064c3e26`.

Полные видео, чужие исходники, автоматические стенограммы и инструменты анализа не включены
в репозиторий продукта. Временный анализ выполнялся локально, распознавание - faster-whisper
small.en на CPU; записи не отправлялись в сторонний сервис транскрибации.

## Изменения плана после видео и кода

- Добавлена карта одного процесса до окончательного выбора scope: actor -> view -> command -> event -> view.
- Уточнено, что разделение долгих effects и решения - проектное решение для Desk.
- Уточнены контекст replay для stateful upgraders и правила переименования JSON-полей.
- Отчет читает сохраненный результат прогона; построение документации не повторяет операции.

Последовательность S1-S7 остается прежней. Учебные реализации помогают проверить модель,
но не заменяют проектирование надежной записи, конкурентности и восстановления для Desk.
